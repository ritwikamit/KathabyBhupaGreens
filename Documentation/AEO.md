# AEO – Answer Engine Optimisation

Make the restaurant's key facts easy for search systems and voice assistants to understand.

## 1. Clear fact block

After owner confirmation, show:
- Full name: Katha by Bhupa Greens.
- Address within the Bhupa Greens campus.
- Exact map pin.
- Phone and email.
- Opening hours.
- Menu categories.
- Reservation/contact method.
- Social links.

Keep this information consistent across the site and public listings.

## 2. Useful FAQs

- Where is Katha by Bhupa Greens located?
- Is Katha inside the Bhupa Greens campus?
- What time does Katha open and close?
- How can I view the menu?
- Does Katha accept table enquiries?
- How do I get directions?
- Where can I read Google reviews?

Answers must match current business information. Do not promise table booking, delivery or a particular menu item unless confirmed.

## 3. Structured data

Use accurate `Restaurant` and `Menu` JSON-LD that mirrors visible content. Validate it before launch. Structured data does not guarantee a rich result or answer-engine placement.

## 4. Writing

Use short direct answers. Put the answer near the start of each section. Use natural local context such as “inside the Bhupa Greens campus in Darbhanga” rather than repeating keywords unnaturally.
