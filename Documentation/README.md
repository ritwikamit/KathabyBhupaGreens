# Katha by Bhupa Greens – Website Documentation

**Prepared:** 24 November 2026  
**Project:** Restaurant website for Katha by Bhupa Greens  
**Build model:** Custom-coded frontend + WordPress headless CMS through the WordPress REST API  
**Agency:** ACCustomLabs

## Project direction

Katha is the restaurant located inside the Bhupa Greens campus in the Darbhanga area of Bihar. The website should present Katha as its own restaurant brand while making the campus location clear. The supplied logo is the primary visual identity. The website frontend is to be custom coded; WordPress is the content backend for menu updates, blog posts and selected media.

## Research caution

Some online listings use slightly different address formats and postal codes for the Bhupa Greens campus. A Google-style business result for Katha currently shows a 4.5 rating from 166 ratings, while an earlier client-supplied figure was 4.7 from 170+ reviews. The number can change, and the figures do not currently match. The website should link to the live Google Maps listing or fetch the latest approved rating instead of hard-coding an unverified number.

The third-party online menu is useful for understanding menu categories, but its prices and availability must be confirmed by the restaurant before publication.
